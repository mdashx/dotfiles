# Practices

Reusable process methods and best-practice writeups.

Use this directory for durable guidance that explains how to work: research
methods, specification practice, orchestration patterns, review methods, and
distillation cycles.

## Boundary

Practice files are content and methodology. They are not automatically standing
instructions unless a project or scenario explicitly routes an agent to them.

```text
agents/     what an agent should obey in a scenario
prompts/    what a human or agent can invoke mid-conversation
practices/  why and how a reusable method works
templates/  blank artifact shapes
examples/   completed reference artifacts
research/   not-yet-promoted notes
```

## Current Process Families

- Conversation-to-spec fieldstones.
- Specification writing.
- Research program orchestration.
- Repository-resident execution orchestration.
- Practice distillation from recent work.
