# Practice Distillation Cycle

Source pattern: this cleanup project and the 2026-09-07 design conversation.

## Purpose

Regularly compile recent work activity into an up-to-date best-practices
library without turning every useful note into standing agent instruction.

## Core Distinction

```text
best practice library != agent instruction dump
```

## Cycle

```text
recent work activity
  -> candidate practices
  -> classification by use context
  -> promotion into the reusable library
  -> examples and provenance retained
  -> next review pass
```

## Classification

- **Agent instruction:** a scenario-specific rule an agent should obey.
- **Prompt:** a reusable conversation frame.
- **Practice:** a durable method or judgment rule.
- **Template:** a fillable artifact skeleton.
- **Example:** a completed project artifact that demonstrates a pattern.
- **Research:** a provisional note or not-yet-promoted policy.

## Promotion Rule

Raw activity becomes notes. Repeated successful judgment becomes practice.
Practice with a clear trigger becomes agent guidance. Practice with a reusable
conversational shape becomes a prompt. Practice with stable fields becomes a
template.

## Review Interval

Run this as a weekly or biweekly pass over recent specs, prompts, agent files,
research notes, tickets, plans, and orchestration artifacts.
