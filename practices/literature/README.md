# Literature

Primary literature underpinning the methods in `../`. These are evidence,
not instruction — a practice file states what we do; a source says where
it came from and lets a disagreement be settled by reading rather than
by argument.

Each source gets a distilled note alongside it so a future reader can get
the load-bearing content without re-reading the original.

| Source | Distilled note | Canonical URL |
| --- | --- | --- |
| Jackson, *Concept Design Moves*, NFM 2022 | `jackson-design-moves.md` | `people.csail.mit.edu/dnj/publications/nfm-design-moves-22.pdf` |

**PDFs are deliberately not committed.** This repository has a GitHub
remote, and redistributing published papers from it is not ours to
decide. The distilled notes are our own writing and are committed; each
records the canonical URL so the original can be re-fetched. A local copy
may sit alongside its note, ignored by git.
