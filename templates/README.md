# Templates

Fillable artifact skeletons.

Use this directory for reusable shapes such as fieldstones, decisions, research
packets, tickets, acceptance matrices, state records, and handoffs.

Templates should be intentionally sparse. Put judgment and method in
`practices/`; put completed examples in `examples/`.

The authoring lifecycle currently includes templates for technical
illustrations, conceptual specifications, implementation plans, fieldstones,
research packets, and orchestration artifacts. A living vision may remain
free-form when a template would constrain exploration prematurely.

## Naming

Prefer names that describe the artifact:

```text
fieldstone.md
research-packet.md
decision-record.md
execution-state.md
acceptance-matrix.md
```
