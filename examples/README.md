# Examples

Completed project artifacts that demonstrate reusable patterns.

Examples preserve source provenance and project context. They are not universal
guidance as written.

Use this directory when a project-local file is valuable as a reference, but
should remain distinguishable from a generalized practice, prompt, or template.

Each example directory should identify the original source path.

Technical illustrations were previously called technical previews. Preserve
that original name in provenance, while classifying new examples under
`technical-illustrations/`.
