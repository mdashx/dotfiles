# Practice Distillation Pass Prompt

Use for a weekly or biweekly review of recent work activity.

```text
Review recent work activity and identify reusable practices without turning
all useful material into standing agent instruction.

Before acting, read these reusable context documents:

- `~/dotfiles/practices/practice-distillation-cycle.md`
- `~/dotfiles/README.md`

Inputs may include specs, prompts, AGENTS files, research notes, tickets,
plans, implementation handoffs, and orchestration artifacts.

For each candidate, classify it as:

- agent instruction;
- prompt;
- practice;
- template;
- example;
- research / provisional note;
- project-local material to leave alone.

Promote only material that is reusable across projects, has a clear use
context, and would improve future work.

Record:

path
current role
recommended destination
action: keep | move | copy | split | leave | archive
reason
confidence
```
