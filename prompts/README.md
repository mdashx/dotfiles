# Prompts

Reusable prompts and mid-conversation working frames.

Use this directory for text that is meant to be invoked during a conversation,
not automatically obeyed as standing machine or project instruction.

## Boundary

```text
agents/     standing scenario instructions
prompts/    reusable conversation frames
practices/  reusable methods and judgment rules
templates/  fillable artifact skeletons
examples/   completed project artifacts
research/   provisional notes and policies
```

Prompts should be concise enough to paste or adapt during active work.

## Current Prompts

- `conversation-to-spec-fieldstone.md` - collect durable design facts during a long conversation.
- `practice-distillation-pass.md` - review recent work for reusable process material.
- `recent-work-catchup.md` - conversationally survey recent machine activity and reconstruct work episodes.
- `repository-resident-orchestration.md` - start a resumable orchestration workspace.
- `research-packet-assignment.md` - assign a bounded research packet.
- `specification-from-fieldstones.md` - write a specification from fieldstones and evidence.
