# Standard Operating Procedures

Procedures an agent reads and follows. Each one states what to do and
enough of why to support judgement.

| SOP | For |
| --- | --- |
| `fieldstone-method.md` | Walking around a topic and collecting what is worth carrying forward |
| `concept-design.md` | Turning a pile of fieldstones into concepts, and writing them down |
| `specification-writing.md` | Writing the specification itself |

## Copyable prompts

A small set of verbs, with any SOP as the argument, rather than one
prompt per SOP. Still to be defined; the shape is:

```text
Read ~/dotfiles/sop/<name>.md and tell me about it.
```

## Boundary

An SOP is a procedure. These are not SOPs and live elsewhere:

- `../templates/` — blank artifact shapes
- `../examples/` — completed reference artifacts
- `../practices/literature/` — primary sources and distilled notes
